Para evitar problemas con archivos demasiado grandes en GitHub, el archivo measurements.txt (868 MB, 1.000.000.000 líneas) no está incluido en este repositorio.

Puedes descargarlo desde Hugging Face en 3 partes y luego unirlas:
🔗 Enlaces de descarga (desde Hugging Face):

  https://huggingface.co/datasets/nietras/1brc.data/blob/main/measurements-1000000000.7z.001

  https://huggingface.co/datasets/nietras/1brc.data/blob/main/measurements-1000000000.7z.002

  https://huggingface.co/datasets/nietras/1brc.data/blob/main/measurements-1000000000.7z.003

Guárdalos en la carpeta csv/ de este repositorio o donde prefieras.

Una vez descargadas las 3 partes:

  Instala 7-Zip si no lo tienes

  Haz clic derecho sobre el archivo measurements-1000000000.7z.001

  Selecciona 7-Zip > Extraer aquí

  Esto generará el archivo completo measurements.txt
